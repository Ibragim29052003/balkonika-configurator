# Балконика · Конструктор отделки

Небольшое статическое приложение для подбора отделки балкона. Собственная SVG-иллюстрация, три цвета стен и три покрытия пола. Без зависимостей, внешних изображений, шрифтов, аналитики и серверной части.

[Открыть конструктор](https://balkonika-interior-ibragim.opal-tang-7471.chatgpt.site) · [Исходный код](https://github.com/Ibragim29052003/balkonika-configurator) · [Пояснение к сдаче](HANDOFF.md)

## Локальный запуск

Требуется Node.js 22 или новее. Установка пакетов и сборка не нужны.

```sh
npm run dev
```

Открыть адрес из терминала. Для публикации достаточно содержимого `dist/` на любом статическом хостинге.

```sh
npm test
npm run check
```

## Структура

- `dist/index.html` — семантический интерфейс и авторская SVG-сцена.
- `dist/styles.css` — оформление и адаптивная вёрстка.
- `dist/materials.js` — варианты отделки и независимые переходы состояния.
- `dist/atmosphere.js` — палитры штор и света, геометрия полотен и параметры освещения.
- `dist/atmosphere-ui.js` — чтение дополнительных настроек формы и обновление SVG.
- `dist/app.js` — связь состояния с интерфейсом.
- `tests/` — проверка сочетаний, независимости выбора и сброса.
- `scripts/serve.mjs` — локальный HTTP-сервер только для разработки.

Стены меняются через CSS-переменную внутри своей SVG-группы. Покрытия пола ограничены общей маской. Окна, мебель и остальные элементы находятся в отдельных слоях. Нативные радиокнопки обеспечивают выбор с клавиатуры; подпись обновляется через `aria-live`. На телефоне превью остаётся видимым при прокрутке настроек; на коротком экране закрепление отключается.

## Дополнительные настройки

В свёрнутом по умолчанию блоке «Ещё немного уюта» можно добавить шторы на дальнее окно: открыть или закрыть их, выбрать один из трёх цветов и длину 120–260 см. Отдельно доступны день/вечер и добавление подвесного светильника с выключателем, тремя температурами и яркостью 10–100%. Удаление штор или светильника сохраняет их настройки до общего сброса.

«Сбросить» возвращает бежевые стены, светлое дерево, день, отсутствие штор и светильника, а также исходные дополнительные параметры. Раскрытие самого блока настроек при этом сохраняется.

Это иллюстрация: высота дальней стены условно принята за 260 см, а освещение показано композиционными слоями SVG. Свет меняет вид сцены, но не значения выбранных материалов. Расчёт освещённости и обмер помещения не выполняются.

## Как внести небольшую правку

Цвета материалов и подписи находятся в `dist/materials.js`; образцы в интерфейсе — в `dist/styles.css`. Чтобы поменять исходное сочетание, нужно обновить `initialSelection` и атрибуты `checked` в HTML. Макет интерьера находится непосредственно в SVG в `dist/index.html`.

Исходные дополнительные параметры заданы в `initialAtmosphere` и начальных значениях формы. После их изменения необходимо проверить общий сброс: он рисует известные начальные значения, поскольку событие `reset` вызывается до восстановления нативных полей браузером.

После изменений запустите проверки и пройдите [сценарии проверки](TESTING.md). GitHub Actions выполняет проверку синтаксиса и тесты при каждом push в `main` и при открытии pull request. Публикуется только `dist/`, локальный сервер разработки для работы приложения не нужен.
