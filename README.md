# Балконика · Конструктор отделки

Небольшое статическое приложение для подбора отделки балкона. Собственная SVG-иллюстрация, три цвета стен и три покрытия пола. Без зависимостей, внешних изображений, шрифтов, аналитики и серверной части.

[Открыть конструктор](https://balkonika-interior-ibragim.opal-tang-7471.chatgpt.site) · [Исходный код](https://github.com/Ibragim29052003/balkonika-configurator) · [Пояснение к сдаче](HANDOFF.md)

## Локальный запуск

Требуется Node.js 22 или новее. Установка пакетов и сборка не нужны.

```sh
npm run dev
```

Открыть адрес из терминала. Для публикации достаточно содержимого `dist/` на любом статическом хостинге.

```sh
npm test
npm run check
```

## Структура

- `dist/index.html` — семантический интерфейс и авторская SVG-сцена.
- `dist/styles.css` — оформление и адаптивная вёрстка.
- `dist/materials.js` — варианты отделки и независимые переходы состояния.
- `dist/app.js` — связь состояния с интерфейсом.
- `tests/` — проверка сочетаний, независимости выбора и сброса.
- `scripts/serve.mjs` — локальный HTTP-сервер только для разработки.

Стены меняются через CSS-переменную внутри своей SVG-группы. Покрытия пола ограничены общей маской. Окна, мебель и остальные элементы находятся в отдельных слоях. Нативные радиокнопки обеспечивают выбор с клавиатуры; подпись обновляется через `aria-live`. Сброс использует начальные значения формы. На телефоне превью остаётся видимым при прокрутке настроек; на коротком экране закрепление отключается.

## Как внести небольшую правку

Цвета материалов и подписи находятся в `dist/materials.js`; образцы в интерфейсе — в `dist/styles.css`. Чтобы поменять исходное сочетание, нужно обновить `initialSelection` и атрибуты `checked` в HTML. Макет интерьера находится непосредственно в SVG в `dist/index.html`.

После изменений запустите проверки и пройдите [сценарии проверки](TESTING.md). GitHub Actions выполняет проверку синтаксиса и тесты при каждом push в `main` и при открытии pull request. Публикуется только `dist/`, локальный сервер разработки для работы приложения не нужен.
