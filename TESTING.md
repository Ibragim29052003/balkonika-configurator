# Проверка перед сдачей и после правок

## Автоматически

```sh
npm run check
npm test
```

Тесты проверяют все девять сочетаний в обоих порядках выбора, независимость поверхностей, неизменность исходного состояния и защиту от некорректных вариантов. Это тесты модели; отображение SVG и поведение формы дополнительно проверяются в браузере.

## В браузере

1. Открыть приложение. Начальное состояние: бежевые стены, светлое дерево; оба варианта выделены.
2. Для каждого из трёх цветов стен последовательно выбрать светлое дерево, тёмное дерево и плитку. Для каждого из девяти сочетаний сверить иллюстрацию, подпись и выделение.
3. При смене стен убедиться, что пол, мебель, остекление и пейзаж не меняются. При смене пола проверить неизменность стен и остальных элементов.
4. Выбрать светло-серые стены и плитку. Нажать «Сбросить» и проверить исходное сочетание, текст и радиокнопки. Повторный сброс должен оставаться безопасным.
5. С помощью Tab перейти к выбору стен, стрелками сменить вариант. Повторить для пола. Проверить видимую рамку фокуса и сброс клавишей Enter.
6. Проверить ширины 320, 375, 390, 768, 1024 и 1440 px. У страницы не должно быть горизонтальной прокрутки; подписи и образцы должны помещаться.
7. На 320 × 568 и 375 × 812 px прокрутить до каждого варианта пола и нажать его. Превью должно оставаться видимым; все варианты и сброс должны нажиматься. На коротком экране в альбомной ориентации закрепление должно отключиться.
8. Проверить опубликованную версию без авторизации: загрузку HTML, CSS и обоих JS-модулей, выбор материалов и сброс.

При изменении палитры дополнительно проверить контраст подписей и заметность активного варианта.
