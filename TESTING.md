# Проверка перед публикацией

## Автоматически

```sh
npm ci
npm run check
npm test
npm run format:check
npm run build
```

29 тестов выполняются через Node.js test runner и tsx. `roomSlice.test.ts` проверяет настоящий Redux store: девять сочетаний в обоих порядках, независимость настроек, геометрию штор, мощность света, границы sliders и полный сброс. `ui.test.tsx` с React Testing Library и jsdom проверяет форму, вкладки, работу селекта, сохранение темы и reset из другой вкладки. jsdom не проверяет WebGL, пиксели, адаптивную вёрстку или реальную доступность скринридером.

## Браузерные сценарии

1. На вкладке «Отделка» выбрать все девять сочетаний. Сверить radio, подпись и вид сцены; окна, мебель и текстиль не должны перекрашиваться вместе с поверхностью.
2. На вкладке «Текстиль» добавить шторы слева. Проверить открытие, закрытие, три цвета и длину 120–260 см. Дальнее окно не меняется. Применить ко всем окнам, затем изменить дальнее окно: левая сторона сохраняет свой вариант.
3. Удалить и вернуть шторы; параметры должны сохраниться. Добавить ковёр и сменить его цвет.
4. На вкладке «Свет» выбрать вечер, три температуры и яркость 10/100%. Выключить свет: источник гаснет и настройки недоступны. Удалить светильник: его геометрия исчезает. Вернуть — настройки сохраняются.
5. Сменить тему. Комната остаётся в прежнем состоянии. Перезагрузить: тема сохраняется, комната возвращается к начальному оформлению.
6. Изменить все параметры и ракурс, затем выполнить общий сброс из любой вкладки. Ожидаются бежевые стены, светлое дерево, день, шторы и ковёр выключены, лампа включена с тёплым светом и яркостью 70%, общий ракурс. Тема не сбрасывается.
7. Проверить radio стрелками, вкладки стрелками/Home/End и select стрелками, Home/End, Enter, Escape, Tab и вводом начальных букв. Меню не должно обрезаться и оставаться после закрытия вкладки.
8. Проверить 320×568, 375×812, 390×844, 768×1024, 1024×768, 1440×1000 и 568×320. Горизонтальной прокрутки нет; кнопки доступны, настройки можно прокрутить. На узком высоком экране превью закреплено, на коротком — нет.
9. Проверить три ракурса и обзор мышью. На телефоне свайп по сцене не должен блокировать прокрутку страницы.
10. Открыть `/?mode=2d`, дождаться упрощённой иллюстрации. Выбор материалов, текстиля, света и сброс продолжают работать; кнопки ракурса скрыты.
11. Проверить консоль и сетевые ошибки. После публикации открыть публичный адрес без регистрации и убедиться, что загружается актуальная сборка.

## Объём проверки версии 2.0

TypeScript, 29 тестов, форматирование, сборка; браузерные проверки девяти сочетаний, текстиля, света, темы, селекта, сброса и перечисленных размеров. В резервном режиме проверена загрузка SVG и смена отделки. Все комбинации дополнительных параметров в браузере не перебирались. Физические телефоны и другие браузерные движки не тестировались.
