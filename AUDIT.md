# Сверка с исходным заданием

| Требование | Результат и подтверждение |
| --- | --- |
| Внутреннее пространство балкона: стены, пол, окна | Собственная SVG-сцена, вид изнутри, остекление слева и впереди. Визуально проверено в браузере. |
| Белые, бежевые, светло-серые стены | Три радиокнопки; каждый цвет проверен. |
| Светлое дерево, тёмное дерево, серая плитка | Три варианта; у дерева и плитки разные текстуры. |
| Меняется только выбранная поверхность | Отдельные SVG-группы и CSS-переменные; пол ограничен clipPath. Остальные настройки сохраняются при выборе отделки. |
| Все сочетания работают | Девять сочетаний проверены без дополнений и ещё девять — со шторами и вечерним светом. Есть автоматические тесты выбора в обоих порядках. |
| Изменения мгновенно, без перезагрузки | Изменение состояния и SVG на клиенте; sliders реагируют на `input`. |
| Активный вариант выделен | Фон, рамка, галочка и нативное checked-состояние. |
| Подпись с текущим выбором | Отдельная подпись «Стены: … Пол: …», доступная как live region. |
| Сброс | Возвращаются материалы, время суток, отсутствие штор и лампы и их исходные параметры; проверено через браузер. |
| Удобство на телефоне | Проверены ширины 320–1440 px и альбомный экран 568 × 320 px. Элементы управления от 44 px, горизонтальной прокрутки нет. На телефоне превью закрепляется во время выбора. |
| Изображения подобраны или созданы самостоятельно | Вся сцена, логотип и иконка созданы в SVG; внешних изображений и шрифтов нет. |
| Нет цены, регистрации, заявок, CRM и серверной части | Приложение целиком статическое. Node.js используется только для локального превью и тестов. |
| Рабочая версия без регистрации | Публичная ссылка Sites; HTML и ресурсы доступны HTTP-запросом без авторизационных cookies. |
| Исходный код | Публичный GitHub-репозиторий, история коммитов, архив исходников. |
| Пояснение: время, AI, проверки | HANDOFF.md. |

Дополнения про шторы и освещение появились по последующему запросу пользователя. Для оценки исходного задания они не обязательны и по умолчанию свёрнуты.

Пределы проверки: viewport менялся в браузере; физических телефонов и полной матрицы браузеров не было. Полный аудит доступности и физический расчёт света не проводились. Эстетическая оценка интерьера остаётся субъективной.
