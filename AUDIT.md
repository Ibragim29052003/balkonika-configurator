# Сверка с исходным заданием

Версия 2.0 развивает тестовое в портфолио-проект. Основной сценарий остаётся на первой вкладке.

| Требование                                   | Реализация и подтверждение                                                             |
| -------------------------------------------- | -------------------------------------------------------------------------------------- |
| Интерьер балкона, видны стены, пол и окна    | Собственная 3D-сцена Three.js, камера внутри; резервная SVG-сцена                      |
| Белый, бежевый, светло-серый цвет стен       | Три radio, отдельный материал стен                                                     |
| Светлое дерево, тёмное дерево, серая плитка  | Три radio, собственные процедурные текстуры                                            |
| Меняется только выбранная поверхность        | Раздельные материалы и геометрия; Redux actions сохраняют остальные параметры          |
| Варианты сочетаются                          | Девять сочетаний проверены в Redux, React-форме и браузерном превью                    |
| Обновление сразу, без перезагрузки           | React + Redux, синхронное обновление визуализатора                                     |
| Видно активный вариант                       | Radio checked, рамка, фон и отметка                                                    |
| Подпись текущего выбора                      | «Стены: … Пол: …» с aria-live                                                          |
| Сброс                                        | Единая фабрика начальной комнаты, контролируемая форма, сброс ракурса; тесты и браузер |
| Телефон                                      | Адаптивная компоновка, крупные контролы, проверка ширин 320–1440 px и короткого экрана |
| Материалы созданы самостоятельно             | Геометрия, Canvas-текстуры, SVG, логотип; внешние изображения не нужны                 |
| Без расчёта цены, регистрации, CRM и сервера | Статическая production-сборка Vite                                                     |
| Открытая рабочая ссылка                      | Публичный GitHub Pages-адрес без регистрации                                           |
| Исходники и пояснение                        | GitHub, README, HANDOFF, TESTING, история коммитов                                     |

Шторы, ковёр, свет, тема, ракурсы и переход на React добавлены по последующим запросам пользователя. Redux Toolkit и 3D не требовались исходным заданием. Тема интерфейса независима от времени суток в комнате.

По реализации базовые требования закрыты. Ограничения: физические телефоны и полная матрица браузеров не проверены; внешний вид стилизован, свет и размеры условные. Новое оформление требует собственной эстетической оценки. Обновлённую версию нельзя представлять как прежнюю 40-минутную работу: после неё были отдельные расширенные этапы.
